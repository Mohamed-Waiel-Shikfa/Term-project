Term project: Salem's adventure

A short description of the project’s name and what it does:
Salem’s Adventure: An animated interactive story, of a young Qatari genius who is going to travel through time to prevent Britain from colonising Qatar in order to make Arabic the more spread language of communication. 

How to run the project:
On pc: Unzip the folder, install the libraries from requierements.txt and run main.py. Don't touch anything else.
On arcade machine: select the game and launch. Wait for it to launch.

How to install any needed libraries:
See previous.

A list of any shortcut commands that exist:
None. If you run the game I prefer that you go through part of it carefully, rather than the entire thing but skipping and not appreciating the details.
